# RCA — Deploy run 50661f01-650c-4e8b-b026-1f5ee5f02800 (sales-dispatch-6)

## Outcome
Build failed at step `build_image` → Cloud Build step #8 `frontend-build-push`. **Source-code fault** — NOT a manifest/infra issue. Fix must be applied in the app source; the deployer cannot fix app code.

## Failure
`frontend-build-push` ran `craco build` which **Failed to compile** with ESLint errors (CRA treats ESLint errors as build failures):

```
[eslint]
src/components/AIHelper.jsx
  Line 157:33:  React Hook "useState" is called conditionally. React Hooks must be
                called in the exact same order in every component render. ...  react-hooks/rules-of-hooks
  Line 158:29:  React Hook "useState" is called conditionally. ...  react-hooks/rules-of-hooks
```

## Root cause
In `frontend/src/components/AIHelper.jsx`, the component `ActionPreviewCard` has an **early return** at line 134:

```js
if (intent === "unknown") {
  return ( ...JSX... );
}
```

Two `useState` hooks were declared **after** that early return (original lines 157–158):

```js
const [editing, setEditing] = useState(null); // field key
const [draft, setDraft] = useState("");
```

When `intent === "unknown"`, the function returns before these hooks run → hooks are called conditionally, violating the Rules of Hooks. `react-hooks/rules-of-hooks` is an error-level rule, so the production build fails.

## Fix (apply in source)
Hoist the two `useState` declarations **above** the `if (intent === "unknown")` early return, so all hooks run unconditionally on every render.

In `frontend/src/components/AIHelper.jsx`, inside `ActionPreviewCard`:

1. **Remove** these two lines (and the two-line comment above them) from their current position (just after the `canConfirm` block / before `startEdit`):
```js
  // Inline field editing inside the preview card. Any field (missing, uncertain, or wrong)
  // is directly clickable and rewritten in-place — no need to type into the chat below.
  const [editing, setEditing] = useState(null); // field key
  const [draft, setDraft] = useState("");
```

2. **Insert** them immediately after the `confidenceColor` declaration and **before** the `if (intent === "unknown") {` early return:

```js
  const confidenceColor = confidence === "high" ? "..."
    : confidence === "medium" ? "..."
    : "...";

  // Inline field editing inside the preview card. ...
  const [editing, setEditing] = useState(null); // field key
  const [draft, setDraft] = useState("");

  if (intent === "unknown") {
    return ( ... );
  }
```

The `startEdit` / `commit` / `cancel` helpers below can stay where they are — they are plain functions (not hooks), so their position is fine. No other hooks exist between the function start and the early return, so this fully resolves the violation.
